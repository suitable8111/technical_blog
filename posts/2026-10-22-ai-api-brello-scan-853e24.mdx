## 청구서를 받고 나서야 알게 되는 AI API 비용

AI API로 서비스를 만들어 보신 분이라면 이런 경험이 한 번쯤 있으실 거예요. 한 달 동안 열심히 개발하고 운영했는데, **청구서를 받고 나서야 비용이 어디에 얼마나 쓰였는지 알게 되는 경우**요.

모델을 바꾸거나, 캐싱을 적용하거나, 프롬프트 구조를 조금만 손봐도 줄일 수 있는 비용이 꽤 있을 텐데, 막상 어디서부터 봐야 할지 막막하죠. 국내 개발 커뮤니티 GeekNews의 'Show GN'에 소개된 **Brello Scan**은 바로 이 고민에서 출발한 무료 도구입니다.

## 핵심 요약

- **무엇을 하나요?** AI API 사용 내역을 분석해서 비용이 새는 곳을 찾아 주고, 개선 방법과 **예상 절감액**을 보여 줍니다.
- **지원 서비스:** 현재는 **OpenAI**와 **Anthropic**을 지원합니다.
- **사용 방법:** 각 서비스 콘솔에서 사용량을 내보낸 뒤, 받은 `.csv` 파일을 넣기만 하면 됩니다.
- **보안:** 분석은 **모두 브라우저 안에서만** 이뤄지고, 데이터는 서버로 전송되거나 저장되지 않습니다. **API 키도 필요 없습니다.**
- **가격:** 무료입니다.

## 어떤 개선 사항을 알려 주나요?

Brello Scan은 지금 쓰고 있는 설정을 기준으로 비용을 줄일 수 있는 지점을 정리해 줍니다. 원문에서 소개한 예시는 이렇습니다.

### 1. 더 저렴한 모델로 바꿔도 되는 호출
모든 요청에 최고 성능 모델이 필요한 건 아닙니다. 간단한 분류, 요약, 포맷 변환 같은 작업은 가벼운 모델로도 충분한 경우가 많아요. 고성능 모델과 경량 모델의 토큰 단가는 꽤 차이가 나기 때문에, 이런 호출을 찾아내는 것만으로도 비용이 눈에 띄게 줄 수 있습니다.

### 2. 캐싱되지 않은 반복 요청
똑같은 시스템 프롬프트나 긴 컨텍스트를 매번 보내고 있다면 **프롬프트 캐싱**을 적용할 여지가 있습니다. OpenAI와 Anthropic 모두 캐싱 기능을 제공하고, 캐시된 입력 토큰은 일반 입력보다 훨씬 싸게 과금됩니다. 반복 요청이 많은 서비스일수록 효과가 커요.

## 왜 '브라우저 안에서만 분석'이 중요할까요?

사용량 데이터에는 어떤 모델을 얼마나 쓰는지, 트래픽이 어떤 패턴인지 같은 **민감한 운영 정보**가 담겨 있습니다. 이런 데이터를 외부 서버에 올리는 건 아무래도 부담스럽죠.

Brello Scan은 모든 분석을 브라우저에서 처리하기 때문에 데이터가 내 컴퓨터 밖으로 나가지 않습니다. 또 API 키를 요구하지 않고 내보낸 CSV 파일만 쓰니까, 키 유출 걱정 없이 써 볼 수 있다는 점도 장점입니다.

## 이런 분들께 추천해요

- AI API 비용이 매달 예상보다 많이 나와서 원인을 찾고 싶은 분
- 사이드 프로젝트나 초기 스타트업처럼 **비용 하나하나가 중요한** 팀
- 모델 선택이나 캐싱 전략을 다시 점검해 보고 싶은 분
- 비용 분석 도구는 쓰고 싶지만 데이터를 외부에 넘기는 건 꺼려지는 분

## 마무리

AI 기능을 붙이는 것만큼이나 **비용을 관리하는 일**도 중요해지고 있습니다. Brello Scan은 CSV 파일 하나로 내 API 사용 패턴을 점검하고 바로 해 볼 수 있는 개선 방향을 알려 준다는 점에서 가볍게 써 보기 좋은 도구예요. 현재는 OpenAI와 Anthropic만 지원하지만, 이 두 서비스를 쓰고 계신다면 다음 청구서가 나오기 전에 한 번 돌려 보시는 건 어떨까요?

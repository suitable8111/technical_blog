Claude나 Cursor 같은 AI 에이전트에게 한국 기업이나 부동산 데이터를 물어봤다가, 그럴듯하지만 어딘가 이상한 답을 받아본 적 있으신가요? GeekNews에 소개된 **korea-data-mcp**는 바로 이 문제를 풀기 위해 만들어진 오픈소스 MCP 서버입니다.

## 핵심 요약

- DART, 공공데이터포털, 국가법령정보 API를 하나의 MCP 서버로 묶은 프로젝트입니다.
- 공공 API 특유의 함정 **47가지**를 서버 단에서 처리해, 에이전트가 데이터를 잘못 해석하지 않도록 돕습니다.
- 제공되는 tool은 **15개**이며, 무료로 발급받은 API 키로 내 컴퓨터에서 직접 실행합니다.

## 왜 필요할까요?

공공 API의 응답을 에이전트에게 그대로 넘기면, 필드의 의미를 오해한 채 자신 있게 틀린 답을 내놓기 쉽습니다.

대표적인 예가 DART 반기보고서입니다. 삼성전자의 2025년 상반기 매출을 물으면 에이전트는 **74.6조 원**이라고 답합니다. 응답의 `thstrm_amount` 값이 반기 누적이 아니라 2분기 3개월치이기 때문입니다. 실제 상반기 누적 매출은 **153.7조 원**으로, 두 배 넘게 차이가 납니다.

필드 이름만 봐서는 알기 어려운 이런 차이가 바로 AI 에이전트가 가장 쉽게 빠지는 함정입니다.

## 어떤 함정을 처리해 주나요?

현재 47개의 함정을 다루고 있으며, 대표적인 사례는 다음과 같습니다.

- **법령**: '현행 법령' 본문에 아직 시행되지 않은 개정 조문이 섞여 있습니다. 기준일에 시행 중인 버전을 골라 주고, 시행 예정 조문은 시행일과 함께 표시합니다.
- **아파트 실거래가**: 해제된 계약이 정상 거래처럼 섞여 들어옵니다. 기본적으로 이를 제외하고 중앙값을 계산합니다.
- **2026년 행정구역 개편**: 옛 지역 코드를 넣으면 지난달 데이터까지 0건으로 나옵니다. 이때 바뀐 코드를 알려 줍니다.
- **기타**: '성공, 0건'으로 돌아오는 잘못된 입력, 만원 단위 금액, 2자리 연도 날짜 등도 처리합니다.

전체 목록은 저장소의 `docs/QUIRKS.ko.md`에서 확인할 수 있습니다.

## 무엇을 조회할 수 있나요?

15개의 tool로 다음 데이터를 다룰 수 있습니다.

- DART 기업·공시·재무제표
- 주가
- 기업 기본정보
- 사업자 상태조회
- 아파트 매매 실거래가
- 공휴일
- 법령·판례

## 설치와 사용 방법

시작하는 과정은 간단한 편입니다.

- **Claude Desktop**: 릴리스의 `.mcpb` 파일을 열면 끝납니다. 공식 MCP Registry에도 등록되어 있습니다.
- **그 외 환경**: 단일 Go 바이너리를 내려받거나 `go install`로 설치할 수 있습니다.
- **API 키**: 직접 발급한 무료 키를 사용합니다. OpenDART 키 하나만 있어도 몇 분이면 시작할 수 있습니다.

모든 처리는 내 컴퓨터에서만 이뤄지며, 제3자 서버를 거치지 않고 텔레메트리도 없습니다. 민감한 조회 내용이 외부로 나갈 걱정을 덜 수 있는 부분입니다.

## 앞으로의 계획

키 발급 없이 URL만으로 쓸 수 있는 호스팅 버전도 준비 중이며, 관심이 있다면 대기 명단에 등록할 수 있습니다. 한국은행 ECOS, KOSIS 등 다음에 추가할 데이터에 대한 의견도 받고 있습니다.

## 에디터의 한마디

AI 에이전트의 정확도는 모델 성능만으로 결정되지 않습니다. 데이터를 어떤 맥락과 함께 전달하느냐도 그만큼 중요합니다. korea-data-mcp는 도메인 지식이 필요한 함정을 서버에서 미리 처리한다는 점에서, 한국 데이터를 다루는 에이전트를 만드는 분들이 눈여겨볼 만한 프로젝트입니다.

프로젝트는 [GitHub 저장소](https://github.com/YoungsoonLee/korea-data-mcp)에서 확인할 수 있습니다.

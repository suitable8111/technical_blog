## 한눈에 보는 핵심 요약

TypeGPU는 타입스크립트 진영에서 주목받고 있는 WebGPU 라이브러리인데요, 이 라이브러리의 개발팀원이 아주 흥미로운 데모를 공개했습니다. 바로 **실시간 깊이 인식 조명 인젝션(Depth-aware light injection)**입니다.

간단히 말하면, 카메라가 찍은 장면의 '깊이(depth)'를 실시간으로 추론하고, 그 정보를 바로 조명 연산에 활용해서 물체 뒤에 가려진 부분까지 자연스럽게 빛이 반응하도록 만드는 기술이에요. 그리고 이 모든 과정이 **GPU 안에서 끊김 없이** 이루어진다는 게 포인트입니다.

## 어떻게 이렇게 빠를 수 있을까?

가장 인상적인 부분은 속도입니다. M4 Pro 환경에서 약 250번의 디스패치(GPU 작업 단위)를 거쳐, 448x448 해상도의 단안 뎁스(monocular depth) 모델 — 즉 카메라 한 대만으로 깊이를 추정하는 모델 — 을 **약 8ms** 만에 처리하는 데 성공했다고 합니다.

8ms가 왜 중요하냐면, 60fps 기준으로 한 프레임에 허용되는 시간이 약 16.7ms인데, 그 절반 정도만 깊이 추론에 쓰고도 실시간 렌더링이 가능하다는 뜻이거든요. 게임이나 AR/VR처럼 프레임 드랍이 치명적인 환경에서도 충분히 써먹을 수 있는 속도입니다.

## 진짜 강점은 '동기화가 필요 없다'는 것

기존에 딥러닝 추론 결과를 그래픽 렌더링에 활용하려면, 보통 다음과 같은 번거로운 과정이 필요했습니다.

- 추론은 별도의 프레임워크(파이토치 등)에서 실행
- 결과 데이터를 CPU로 가져오거나, GPU 간 인터롭(interop) 처리
- 동기화 대기 시간 발생 → 오버헤드 증가

하지만 이번 구현은 추론 로직 자체를 **TypeGPU로 직접 작성**했기 때문에 이런 병목이 통째로 사라집니다. 뎁스 모델이 GPU 위에서 만들어낸 뎁스 버퍼를 그 자리에서 곧바로 라이팅 패스(조명 연산 단계)에 밀어 넣을 수 있는 거죠. 데이터가 GPU 밖으로 나갈 필요도, 별도의 동기화 단계를 거칠 필요도 없습니다.

더 나아가 **추론 → 조명 연산 → 드로우(draw)** 까지의 전 과정이 하나의 커맨드 인코더(command encoder)로 실행됩니다. 쉽게 말해, 웹 페이지 안에서 실행되는 그래픽 파이프라인 하나가 딥러닝 추론까지 통째로 품고 있는 셈입니다.

## 왜 주목해야 할까요?

지금까지 웹 환경에서의 실시간 딥러닝 추론과 그래픽스 렌더링은 서로 다른 생태계처럼 다뤄지는 경우가 많았습니다. 이번 사례는 **WebGPU + TypeScript** 조합만으로도 딥러닝 추론과 렌더링을 하나의 파이프라인으로 완전히 통합할 수 있다는 걸 보여준 좋은 예시입니다.

특히 브라우저 기반의 인터랙티브 3D 콘텐츠, AR 필터, 웹 게임 등에서 별도의 서버나 네이티브 앱 없이도 이런 수준의 실시간 조명 효과를 구현할 수 있다는 가능성을 시사합니다. 원문 트윗에는 실제 시연 영상도 함께 공개되어 있으니, 관심 있으신 분들은 꼭 확인해보시길 추천드려요.

## 정리

- **무엇을**: 단안 뎁스 모델 추론 + 조명 연산을 GPU 내부에서 통합 처리
- **어떻게**: TypeGPU로 추론 로직을 직접 작성해 CPU-GPU 동기화 오버헤드 제거
- **얼마나 빠르게**: M4 Pro 기준 448x448 해상도, 약 8ms
- **의의**: 웹 환경에서 딥러닝 추론과 그래픽 렌더링 파이프라인의 완전한 통합 가능성 제시

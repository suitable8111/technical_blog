## 한 줄 요약

**GNUCMS**는 일반 웹호스팅(카페24 등)에 FTP로 파일을 올리고 브라우저에서 설치 화면만 거치면 바로 돌아가는 PHP 기반 커뮤니티·콘텐츠 관리 시스템입니다. 별도의 애플리케이션 서버도, 빌드 과정도, 서버에서의 Composer 실행도 필요 없습니다.

## 왜 눈여겨볼 만한가

요즘 웹 스택은 강력하지만 그만큼 손이 많이 갑니다. Node 런타임을 띄우고, 빌드를 돌리고, DB 서버를 따로 준비해야 하죠. 반면 국내 소규모 사이트나 동호회 커뮤니티는 여전히 "저렴한 웹호스팅 한 칸"에서 출발하는 경우가 많습니다. GNUCMS는 바로 그 지점을 정확히 겨냥합니다.

- **설치 장벽이 낮음**: zip 배포본에 `vendor/`가 이미 포함되어 있어, 서버에서 Composer를 돌릴 수 없는 환경에서도 그대로 동작합니다.
- **DB 선택의 자유**: SQLite / MySQL·MariaDB / PostgreSQL 중 원하는 것을 고를 수 있습니다. 특히 **SQLite만으로도 운영 가능**해서, DB 서버를 제공하지 않는 호스팅에서도 부담이 없습니다.
- **서버 사이드 렌더링 기본**: Slim 프레임워크 위에 순수 PHP 템플릿 엔진을 얹은 구조라, 프론트엔드 빌드 파이프라인 자체가 존재하지 않습니다.

## 주요 기능 정리

### 게시판
- 게시판별 **읽기·쓰기·댓글 권한**을 각각 설정
- 분류(카테고리), 공지, 비밀글, 첨부 파일 지원
- 화면 유형이 다양함: **목록형 · 갤러리형 · 매거진형 · 뉴스형**

### 회원·인증
- 이메일 가입, 인증 메일, 비밀번호 재설정
- **Google · 네이버 · 카카오** 소셜 로그인 연동

### 운영·법적 요구사항
- 일반 문서는 물론 **이용약관·개인정보 처리방침**을 작성하고, 사용자의 **동의 증적까지 기록**
- 국내 서비스 운영 시 은근히 손이 많이 가는 부분인데, 기본 기능으로 들어가 있다는 점이 인상적입니다.

### SEO·배포
- 사이트맵, `robots.txt` 자동 생성
- 사이트 / 문서 / 게시판 단위 **RSS 자동 제공**

### 스팸·도배 방지
- 글·댓글 등록 **간격 제한** + **10분 단위 / 하루 단위 한도** 설정
- **Cloudflare Turnstile** 연동으로 봇 차단

### 유지보수
- DB 구조 **자동 갱신**(마이그레이션)을 지원하며, SQLite의 경우 **갱신 전 자동 백업**을 수행합니다.

## 설치 요구 사항

| 항목 | 내용 |

| PHP 버전 | 8.2 이상 (8.4 권장) |
| 필수 확장 | PDO, mbstring, fileinfo, openssl |
| 라이선스 | MIT |
| 현재 버전 | 0.2.0 |

## 어떤 경우에 잘 맞을까

- 소규모 커뮤니티나 동호회 사이트를 **빠르게, 저렴하게** 올리고 싶을 때
- Docker나 CI/CD 같은 인프라 없이 **FTP만으로 운영**해야 하는 환경
- 기존 PHP 게시판 솔루션에 익숙하지만, **최신 PHP(8.2+)와 MIT 라이선스** 기반의 대안을 찾고 있을 때

다만 버전이 아직 **0.2.0**이라는 점은 감안해야 합니다. 실서비스에 바로 투입하기보다는, 먼저 테스트 환경에서 필요한 기능이 충분한지 확인해 보는 편이 안전합니다. MIT 라이선스이므로 필요한 부분을 직접 수정해 쓰기에도 제약이 없다는 점은 큰 장점입니다.

## 마치며

"복잡한 배포 없이 그냥 올리면 돌아가는" 방식은 한동안 구식처럼 여겨졌지만, 목적에 따라서는 여전히 가장 합리적인 선택입니다. GNUCMS는 그 방식을 최신 PHP 생태계 위에서 다시 구현한 프로젝트라고 볼 수 있겠습니다.

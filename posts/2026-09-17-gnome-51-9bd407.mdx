GNOME 51이 공개됐습니다. 이번 릴리스는 화려한 신기능을 전면에 내세우기보다, **데스크톱이 실제로 얼마나 매끄럽게 동작하는가**에 집중한 인상이 강합니다. 그러면서도 Maps의 오프라인 지도처럼 체감이 확실한 기능도 함께 들어왔습니다. 핵심만 먼저 짚고, 영역별로 하나씩 살펴보겠습니다.

## 한눈에 보는 핵심 요약

- **성능**: Mutter의 프레임 스케줄링과 화면 녹화 처리를 개선해 부하가 높을 때도 애니메이션이 더 부드러워짐
- **Maps**: 오프라인 지도 다운로드 지원, 대중교통 안내에 실시간 운행 정보와 도보 이동 시간 추가
- **인증**: 원격 데스크톱의 스마트카드 전달과 Kerberos 인증 지원, 로그인 화면에서 웹 기반 로그인 등 다양한 인증 수단 선택 가능
- **접근성**: 동작 줄이기 적용 범위 확대, 키보드만으로 스크린샷 영역 조정, 화면 읽기 기능 개선
- **정리(제거)**: 레거시 NVIDIA 드라이버 인터페이스와 WEP 지원 제거, Software는 유지보수 종료 앱 설치 전 경고

## 그래픽 성능과 디스플레이 설정

이번 릴리스에서 가장 근본적인 변화는 컴포지터인 **Mutter** 쪽에 있습니다. 프레임 스케줄링과 화면에 프레임을 전달하는 체계를 재작업해, 시스템 부하가 높은 상황에서도 애니메이션이 끊기지 않고 흐르도록 다듬었습니다. 화면 녹화 역시 중복 작업과 버퍼 복사를 줄였습니다. 녹화를 자주 사용하는 분이라면 체감 차이가 있을 부분입니다.

소소하지만 반가운 변화도 있습니다.

- 모니터 밝기가 재부팅 후에도, HDR을 껐다 켜도 그대로 유지됩니다.
- 디스플레이 설정에 **자동 회전과 방향 잠금**이 추가됐습니다. 가속도계가 있는 기기라면 세로/가로가 자동 전환되고, 자동 회전을 켠 상태에서 현재 방향만 고정할 수도 있습니다.
- 디스플레이 배치에 **중앙 정렬 스냅**이 생겨, 실제 책상 위 모니터 배치와 맞추기가 훨씬 수월해졌습니다.
- 포인터 커서를 정적 비트맵이 아닌 **SVG**로 렌더링합니다. 고해상도 모니터와 저해상도 모니터를 섞어 쓸 때 커서가 뭉개지던 문제를 구조적으로 해결한 셈입니다.

한편 **레거시 NVIDIA 드라이버 인터페이스 지원은 제거**되고, 최신 표준 그래픽 인터페이스만 사용하도록 바뀌었습니다. 오래된 NVIDIA 환경을 쓰고 있다면 업그레이드 전에 드라이버 상태를 한 번 확인해 보시길 권합니다.

## 입력 장치, 네트워크, 그리고 인증

노트북 사용자라면 **마우스 연결 시 터치패드 자동 비활성화** 옵션이 눈에 들어올 겁니다. 그동안 별도 설정 도구로 해결하던 부분이 기본 설정에 들어왔습니다.

네트워크 쪽에서는 **DNS 검색 도메인 설정**이 추가됐고, 반대로 오래된 무선 보안 표준인 **WEP 지원은 완전히 제거**됐습니다. 보안 관점에서는 당연한 수순이지만, 구형 장비를 쓰는 환경이라면 미리 대비가 필요합니다.

인증 관련 변화는 특히 업무 환경에서 의미가 큽니다.

- 원격 데스크톱에서 **내 컴퓨터에 연결한 스마트카드를 원격 컴퓨터에서 그대로 사용**할 수 있습니다.
- **Kerberos** 환경에서는 추가 단계 없이 원격 사용자 세션에 바로 로그인됩니다.
- 로그인 화면에서 여러 인증 방식을 선택할 수 있고, 구성된 환경에서는 **웹 기반 로그인**도 지원합니다.
- 원격 로그인은 기존 서비스 기반 구성에 더해 **SSH 소켓 서버**를 지원합니다.
- 암호와 키의 저장·조회에는 보안을 강화한 새 구성 요소 **oo7**을 사용합니다.

그 밖에 지문 등록 인터페이스가 개선됐고, 시스템 정보 페이지가 재구성되면서 현재 GNOME 버전의 릴리스 노트를 바로 여는 버튼이 생겼습니다.

## Maps: 오프라인 지도와 실시간 대중교통

이번 릴리스에서 일반 사용자가 가장 반길 기능입니다.

**오프라인 지도**로 원하는 지역을 미리 내려받아 네트워크 없이 사용할 수 있습니다. 로밍 요금이 부담스러운 해외여행, 연결이 불안정한 지역, 지하나 산간 같은 통신 음영 지역에서 진가를 발휘합니다. 다운로드한 지역은 목록에서 확인하고 삭제할 수 있어 저장 공간 관리도 간단합니다.

**대중교통 안내**도 크게 보강됐습니다.

- 데이터가 제공되는 지역에서는 역이나 정류장을 누르면 **실시간 출발·도착 시간**을 확인할 수 있습니다.
- 경로 안내에 **실시간 지연 정보**와 이용할 승강장/정류장이 표시됩니다.
- 여정에 정류장까지 걸어가는 시간, 정류장에서 나오는 도보 시간까지 포함됩니다.

환승 세부 정보와 도보 시간이 함께 나온다는 점에서, 상용 지도 앱에 익숙한 사용자도 무리 없이 쓸 수 있는 수준에 가까워졌습니다.

## Files, Web, Software

### Files

파일 선택과 상태 표시, 전반적인 반응성이 개선됐습니다.

- 여러 파일을 드래그할 때 **배지로 항목 수**를 표시합니다.
- 복사로 생성된 파일이 자동 선택되고, 폴더 빈 공간을 우클릭해도 기존 선택이 유지됩니다.
- 읽기 전용이거나 읽을 수 없는 폴더의 상태 표시를 바로잡고, 여러 표시가 겹칠 때 우선순위를 적용합니다.
- 느린 작업이 앱 전체를 멈추지 않도록 개선했고, 크거나 느린 폴더의 화면 새로고침 속도를 높였습니다.
- 알림을 그룹화해 찾고 관리하기 쉬워졌습니다.

### Web

- `Ctrl+Shift+C`로 주소창을 열지 않고 **현재 페이지 주소를 복사**할 수 있습니다.
- `pwquality` 라이브러리로 강력한 암호를 생성하며, 암호 관리자 버그도 수정됐습니다.
- 주소창 드롭다운의 검색 엔진 제안에서 URL을 숨겨 목록이 간결해졌습니다.

### Software

- **유지보수가 종료된 앱**을 설치하려 하면 진행 전에 경고합니다. 보안 업데이트가 끊긴 앱을 모르고 설치하는 상황을 줄여 줍니다.
- Flatpak 파일 권한 목록을 확장해, 앱이 접근할 수 있는 범위를 더 자세히 확인할 수 있습니다.
- 시작 시 캐시된 앱 데이터를 재사용하고 아이콘 로딩을 최적화해 실행이 빨라졌습니다.

## Calendar와 미리보기 도구들

**Calendar**는 내부를 재작업해 반응성을 높이고 동기화 시 백그라운드 데이터 사용량을 줄였습니다. 일정이 많아도 월 보기 스크롤과 다시 그리기가 부드러워졌고, 큰 캘린더를 열고 탐색하는 속도도 개선됐습니다. 일정의 장소를 Maps에서 바로 열 수 있고, 주 보기의 고대비 지원 문제와 일정 편집기의 메모 영역, Microsoft Teams 회의 링크 지원도 손봤습니다.

**Loupe**(이미지 뷰어)는 속성에 제작자, 저작권, 카메라 렌즈와 장비, 제작 소프트웨어 정보가 추가됐습니다. 이미지에 내장된 색상 프로파일도 표시해 광색역 여부와 색 공간을 확인할 수 있습니다. 사진 작업을 하는 분들에게 유용한 변화입니다.

**Sushi**(파일 선택 후 Space로 여는 빠른 미리보기)는 GTK 4와 libadwaita 기반으로 전면 개편됐습니다. 데스크톱과 일관된 디자인, 다크 모드, 이미지 실제 크기 표시를 지원하고, GNOME의 다른 구성 요소와 동일한 최신 이미지 로딩·문서 렌더링 라이브러리를 사용합니다.

## Papers: 손글씨 서명을 문서에 바로

문서 뷰어 **Papers**에 시각적 서명 기능이 들어왔습니다. 별도 하드웨어나 인증서 없이 문서를 우클릭해 새 서명을 만들거나 저장된 서명을 고를 수 있습니다. 마우스나 터치스크린으로 직접 그릴 수도 있고, 손글씨 서명 이미지를 가져올 수도 있는데 **이미지 배경은 자동으로 제거**됩니다.

다만 한 가지는 분명히 알아 둘 필요가 있습니다. 이 시각적 서명은 **디지털 서명과 달리 문서의 진위를 보장하지 않습니다.** 암호학적 검증이 아니라 "서명처럼 보이는 그림"에 가깝습니다. 그럼에도 실무에서는 이런 형태의 서명이 널리 쓰이기 때문에, 각종 서류를 처리할 때 충분히 실용적입니다.

이 밖에 문서 속성의 용지 크기 정보가 더 상세해졌고, 자유 텍스트 주석이 기본적으로 인쇄에 포함됩니다. GTK의 새 스냅 API를 활용해 소수 배율 렌더링을 개선했고, 미리보기 창의 크기와 최대화 상태를 기억합니다.

## 접근성 개선

- **동작 줄이기** 설정이 셸과 여러 핵심 위젯 등 더 많은 영역에 적용돼, 애니메이션을 실질적으로 줄일 수 있습니다.
- **스크린샷 영역 선택을 키보드만으로** 조정할 수 있습니다. 방향키로 크기를 바꾸고, `Alt`를 누른 채 영역을 이동하며, `Shift`/`Ctrl`로 큰 단위·미세 단위를 조정하고, `R`로 영역을 초기화합니다.
- 접근성 설정에 **포커스 표시 시간 제한 해제** 옵션이 추가돼, 보조 기술이 인터페이스 요소와 상호작용할 시간을 더 확보할 수 있습니다.
- 화면 읽기 기능은 앱 독을 두 번 읽지 않으며, 검색 결과 안내와 앱 그리드 탐색이 개선됐습니다.

## 커뮤니티와 사용해 보는 방법

GNOME 플랫폼 기반 커뮤니티 앱을 지원하는 **GNOME Circle**에 세 프로젝트가 새로 합류했습니다. 기본 배경화면 디자인도 새로워졌고, 배경화면 선택기에서 추가 변형을 고를 수 있습니다. 플랫폼 개발자를 위한 변경 사항은 별도의 개발자 문서에서 확인할 수 있습니다.

GNOME 코드는 적용 라이선스에 따라 자유롭게 다운로드·수정·공유할 수 있는 자유 소프트웨어입니다. GNOME 51은 **향후 몇 주 내 주요 Linux 배포판에서 제공될 예정**이며, 먼저 써 보고 싶다면 GNOME OS Nightlies를 가상 머신이나 실제 하드웨어에서 시험해 볼 수 있습니다. 최신 GNOME 앱은 Flathub에서도 이용할 수 있습니다.

## 마치며

GNOME 51은 "새로 생긴 것"과 "드디어 정리된 것"이 균형 있게 담긴 릴리스입니다. Mutter의 프레임 처리 재작업과 Calendar·Files의 반응성 개선은 매일 쓰는 사람일수록 체감이 클 부분이고, Maps의 오프라인 지도와 Papers의 서명 기능은 명확한 쓰임새가 있습니다. 반대로 레거시 NVIDIA 인터페이스와 WEP 제거는 업그레이드 전에 한 번쯤 점검이 필요한 항목입니다. 배포판에 올라오면 직접 확인해 보시길 권합니다.

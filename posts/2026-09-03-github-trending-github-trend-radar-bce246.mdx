## 한눈에 보는 요약

- **문제**: GitHub Trending 상위권은 이미 커뮤니티에서 여러 번 회자된 저장소가 대부분이라, '아직 안 유명하지만 반응이 오기 시작한' 프로젝트를 찾기 어렵다.
- **해결**: 개발자가 직접 만든 **GitHub Trend Radar**는 2시간마다 GitHub 데이터를 갱신해, 세 가지 서로 다른 기준으로 저장소 순위를 매긴다.
- **특징**: 가입 없이 바로 사용 가능, 한국어·영어 및 라이트·다크 모드 지원, 점수 계산법과 한계까지 공개.

## 왜 만들었을까

제작자는 스스로를 얼리어답터라고 소개합니다. 새 도구를 빨리 써보고 괜찮으면 주변에 공유하는 걸 즐기는 타입이죠. 그런데 매일 GitHub Trending을 들여다봐도, 상위권에 올라온 저장소는 이미 Threads나 각종 커뮤니티에서 몇 번씩 마주친 것들이었습니다.

정작 찾고 싶은 건 **"아직 잘 알려지지 않았지만, 슬슬 반응이 오기 시작한"** 프로젝트였습니다. 그러려면 GitHub를 직접 뒤져야 했고, 이 작업을 매일 반복하는 건 꽤 번거로운 일이었습니다. 그래서 "내가 보고 싶은 방식대로 아예 만들어버리자"는 결론에 도달했습니다.

> 좋은 사이드 프로젝트는 대부분 이런 지점에서 출발합니다. 남들이 겪는 문제가 아니라, **내가 매일 겪는 불편**에서요.

## 핵심은 '세 가지 랭킹'

GitHub Trend Radar가 기존 Trending과 결정적으로 다른 부분입니다. 하나의 인기 순위 대신, 성격이 다른 세 개의 렌즈를 제공합니다.

### 1. 모멘텀 (Momentum)
요즘 스타가 **꾸준히** 늘고 있는 저장소를 잡아냅니다. 한 번 확 튀었다가 식는 프로젝트가 아니라, 안정적인 성장 곡선을 그리는 저장소를 보고 싶을 때 유용합니다.

### 2. 급부상 (Rising)
이 서비스의 핵심 아이디어에 가장 가까운 지표입니다. **공식 GitHub Trending에 오르기 전**, 빠르게 성장하는 소규모 저장소를 찾아줍니다. 절대적인 스타 수가 아니라 성장 속도에 초점을 맞추기 때문에, 규모가 작아 기존 랭킹에 묻히던 프로젝트가 드러납니다.

### 3. 현재 열기 (Heat)
스타 증가 속도뿐 아니라 **참여자 수, 활동의 종류, 반응이 이어지는 정도**까지 종합합니다. 지금 이 순간 관심이 몰려 있는 저장소를 보여주는, 가장 실시간성이 강한 지표입니다.

## 그 밖의 기능들

- **언어·토픽 필터링**: 관심 있는 기술 스택으로 좁혀서 탐색
- **과거 순위 조회**: 지난 랭킹을 되짚어보며 흐름 확인
- **공식 Trending과 비교**: 두 랭킹의 결과가 어떻게 다른지 나란히 확인
- **발굴 성과 페이지**: 실제로 GitHub Trending보다 **먼저** 찾아냈는지를 별도로 기록

마지막 항목이 특히 인상적입니다. "우리가 더 빨리 찾습니다"라고 주장만 하는 대신, 그 주장을 검증할 수 있는 기록을 서비스 안에 만들어 둔 셈이니까요. 다만 제작자도 밝혔듯 아직 서비스를 시작한 지 얼마 되지 않아, 의미 있는 성과를 보려면 데이터가 더 쌓여야 합니다.

## 투명하게 공개한 점수 계산법

랭킹 서비스에서 가장 아쉬운 부분은 대개 "그래서 이 순위는 어떻게 나온 건데?"라는 물음에 답이 없다는 점입니다. GitHub Trend Radar는 **점수 계산 방식과 그 한계를 사이트 안에 명시**해 두었습니다. 지표를 신뢰할지 판단할 재료를 사용자에게 넘겨준다는 점에서, 이런 태도는 충분히 눈여겨볼 만합니다.

## 사용해보기

- 가입 절차 없이 **바로 사용 가능**
- **한국어 / 영어** 지원
- **라이트 / 다크 모드** 지원

제작자는 피드백을 요청하고 있습니다. 특히 두 가지 질문에 대한 답을 궁금해합니다.

1. 세 가지 랭킹이 실제로 **서로 다르게** 느껴지는가?
2. 첫 화면에서 그 **차이가 잘 보이는가**?

비슷한 지표 세 개를 나열하는 데 그치면 사용자 입장에서는 그냥 하나의 순위와 다를 게 없습니다. 반대로 세 렌즈가 확실히 다른 저장소를 보여준다면, 이 서비스는 GitHub Trending을 대체하는 게 아니라 **그보다 한 발 앞선 레이어**로 자리 잡을 수 있을 겁니다.

새로운 오픈소스 프로젝트를 남들보다 먼저 발견하고 싶은 분이라면, 한 번 둘러볼 만한 도구입니다.

## 한 줄 요약

**OpenCode Browse**는 MCP 서버와 Chromium 확장 프로그램을 함께 써서, 코딩 에이전트가 **사용자가 평소 쓰는 브라우저**를 그대로 이용하게 해 주는 도구입니다. 열어 둔 탭, 로그인 상태, 설치한 확장 프로그램까지 그대로 쓸 수 있습니다.

---

## 왜 주목할 만할까요?

지금까지 에이전트에게 웹 작업을 시키려면 대부분 헤드리스 브라우저나 새로 띄운 깨끗한 프로필을 써야 했습니다. 그러다 보니 이런 불편함이 따라왔죠.

- 로그인이 필요한 사이트에 접근하려면 쿠키나 토큰을 따로 넘겨야 함
- 2FA나 캡차 앞에서 에이전트가 멈춤
- 평소 쓰던 확장 프로그램을 쓸 수 없음

OpenCode Browse는 **에이전트를 사용자의 실제 브라우저 안으로 들여보내는 방식**으로 이 문제를 풉니다. 이미 로그인한 사이트는 **별도 키나 설정 없이** 바로 접근할 수 있습니다.

---

## 주요 기능

### 🧭 실제 브라우저에서 작업
- 페이지 **읽기, 클릭, 입력** 같은 기본 조작을 지원합니다
- **스크린샷 촬영**, **탭 녹화**, **네트워크 트래픽 캡처**도 할 수 있어 디버깅이나 QA 작업에 쓰기 좋습니다

### 🗂️ 작업 공간 분리
- 에이전트가 여는 탭은 **백그라운드의 접힌 탭 그룹**에 모입니다. 내가 보고 있는 화면을 어지럽히지 않습니다
- 반대로 툴바 버튼을 누르면 **내가 열어 둔 탭을 에이전트에게 넘길** 수도 있습니다

### 🤝 사람과 에이전트 사이의 인계
- **로그인, 2FA 인증, 결제**처럼 사람이 직접 해야 하는 단계에서는 에이전트가 탭을 사용자에게 넘깁니다
- 사용자가 직접 처리한 뒤 **Continue** 버튼을 누르면 에이전트가 이어서 작업합니다

민감한 단계는 사람이 맡고 반복 작업은 에이전트가 맡는, 현실적인 분업 방식입니다.

### 🔒 접근 범위 제한
- **허용 사이트**를 지정하면 에이전트 탭이 그 사이트 안에서만 움직이도록 제한할 수 있습니다
- 실제 로그인 세션을 쓰는 만큼, 이 설정은 사실상 필수에 가깝습니다

MCP 표준을 따르기 때문에 특정 에이전트에 묶이지 않습니다. 지금 쓰는 도구에 그대로 붙일 수 있습니다.

## 설치 방법

1. **Chrome 확장 프로그램을 먼저 설치**합니다
2. 확장 프로그램이 나머지 설치 단계를 안내합니다
3. CLI로 직접 설치하는 방법도 있지만, 일반적으로는 필요하지 않습니다

소스 코드는 **GitHub 저장소**에 공개되어 있어 동작 방식을 직접 확인할 수 있습니다.

- 중요한 계정은 **별도 브라우저 프로필**로 분리하기
- 네트워크 캡처나 녹화 결과로 **에이전트가 무엇을 했는지 확인**하기

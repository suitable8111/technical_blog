## 로지텍 마우스 쓰면서 이런 불편, 없으셨나요?

MX Master 시리즈 같은 로지텍 프리미엄 마우스를 쓰려면 사실상 **Logi Options+**를 설치해야 합니다. 그런데 이 앱, 버튼 하나 커스터마이징하려고 계정 로그인을 요구하고, 백그라운드에서 클라우드 동기화며 사용 데이터 수집을 은근슬쩍 진행하죠. "그냥 DPI랑 버튼 매핑만 바꾸고 싶은데..." 싶었던 분들에게 반가운 소식이 있습니다. 바로 **OpenLogi**라는 오픈소스 대안 앱입니다.

## OpenLogi가 뭐가 다른가요?

OpenLogi는 Rust로 만들어진 네이티브 앱으로, 로지텍과는 무관한 독립 오픈소스 프로젝트입니다(MIT·Apache-2.0 이중 라이선스). 핵심 차별점은 명확합니다.

- **계정 로그인 불필요**
- **클라우드 동기화 없음**
- **텔레메트리·사용 추적·충돌 리포트 전송 없음**
- 네트워크 요청은 딱 두 가지 용도로만 사용 — 장치 이미지 다운로드, 그리고 기본적으로 꺼져 있는 선택적 업데이트 확인

대신 **HID++ 프로토콜**을 통해 설정값을 장치에 직접 기록하는 방식으로 동작합니다. 즉, 내 마우스 설정이 어딘가의 서버가 아니라 오롯이 내 컴퓨터와 장치 안에만 존재하는 거죠.

## 뭘 할 수 있나요?

- **버튼 커스터마이징**: 대화형 마우스 그림에서 물리 버튼을 클릭해 44개 내장 동작, 사용자 지정 단축키, 앱 실행, 스크립트 실행 등을 자유롭게 지정
- **DPI 프리셋**: 센서에 직접 해상도 값을 기록 (HID++ 0x2201 사용)
- **SmartShift 제어**: 스크롤 휠을 래칫 모드/자유 회전 모드로 전환하거나 속도에 따라 자동 전환 (HID++ 0x2111 사용)
- **앱별 프로필**: 포커스된 애플리케이션이 바뀌면 설정이 즉시 자동 전환됨
- **배터리 상태 확인**: 연결된 장치를 카러셀 형태로 보여주고, 배터리 잔량과 충전 상태까지 표시

특히 인상적인 부분은 모든 바인딩·프리셋·프로필이 `~/.config/openlogi/config.toml` 같은 **단일 평문 TOML 파일**에 저장된다는 점입니다. GUI로 편하게 설정해도 되고, 원한다면 파일을 직접 텍스트 에디터로 열어 수정할 수도 있죠. 개발자 친화적인 설계입니다.

## 지원 장치와 연결 방식

**마우스**: MX Master 4 / 3S / 3, MX Anywhere 3, Signature M650, Ergo M575

**키보드**: F열 재매핑, Fn Lock, RGB·백라이트 제어 지원

그 외 **Litra 조명**, **로지텍 웹캠**도 지원 목록에 포함되어 있습니다.

연결 방식은 Logi Bolt·Unifying·Lightspeed 수신기는 물론, 직접 Bluetooth 연결과 USB 케이블까지 모두 아우릅니다.

## 설치 방법

- **macOS**: `brew install --cask openlogi` 한 줄로 끝. 서명·공증된 .dmg 파일도 제공되며 Apple Silicon과 Intel 모두 지원
- **Linux**: amd64·arm64용 .deb, .rpm, Arch용 .pkg.tar.zst 패키지 제공. udev 규칙과 systemd 사용자 유닛도 포함되어 있어 설치가 매끄러움
- **Windows**: 가장 최근에 추가된 플랫폼. Windows 11 실기기에서 검증된 x86_64·arm64용 서명 .msi 제공

## 설치 전 꼭 확인할 것

HID++ 프로토콜 특성상, **한 번에 하나의 프로그램만 장치 접근 권한을 가질 수 있습니다.** 따라서 OpenLogi를 실행하기 전에는 반드시:

- macOS/Windows: Logi Options+와 메뉴 막대 에이전트를 종료
- Linux: Solaar(리눅스용 로지텍 장치 관리 도구)를 종료

이 과정을 건너뛰면 두 프로그램이 같은 수신기를 동시에 점유하려다 충돌이 날 수 있으니 유의하세요.

## 정리하며

"내 마우스 설정 하나 바꾸는데 왜 계정을 만들고 클라우드에 접속해야 하지?"라는 물음에 정면으로 답한 프로젝트가 OpenLogi입니다. 프라이버시를 중시하거나, 가벼운 네이티브 앱을 선호하거나, 설정 파일을 직접 관리하고 싶은 로지텍 사용자라면 한 번쯤 시도해볼 만한 선택지입니다.

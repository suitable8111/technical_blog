## 한 줄 요약

**SAMI Suite**는 HWP·HWPX, 워드, 엑셀, 파워포인트, PDF 파일을 **설치나 회원가입 없이** 브라우저에서 바로 열고 편집할 수 있는 무료 웹 오피스입니다. WebAssembly(WASM) 기반이라 **문서를 서버로 올리지 않고 내 기기의 브라우저 안에서 처리**한다는 점이 가장 큰 특징이에요.

로컬 문서 검색 도구 **Findex**를 만든 사미텍에서 GeekNews에 직접 소개한 프로젝트입니다.

---

## 왜 만들었을까?

문서를 찾은 뒤 내용을 확인하거나 조금 고치려 해도, 파일 형식에 맞는 프로그램이 있어야 하죠. 이런 경험 다들 있으실 거예요.

- HWP 문서에서 **문구 하나**만 고치고 싶을 때
- 엑셀 표를 **살짝** 수정해야 할 때
- PDF에 **서명 하나** 넣어야 할 때

이런 작은 작업을 하려고 무거운 프로그램을 따로 설치하고 실행하는 건 꽤 번거롭습니다. SAMI Suite는 이런 작업을 **브라우저 한 곳에서** 끝내는 것을 목표로 만들어졌어요. 그리고 개발팀은 **문서를 외부 서버에 맡기지 않는 구조**를 특히 중요하게 생각했다고 합니다.

개발자는 최근 ArtCraft가 공개한 여러 프로젝트를 살펴본 뒤, 오피스 분야만큼은 자신들이 만들던 쪽이 더 낫다고 판단해 공개를 결정했다고 하는데요. 특히 **한컴 문서(HWP)를 지원한다**는 점을 강점으로 내세웠습니다.

## 지금 할 수 있는 일

### 📝 Writer
- HWP·HWPX·DOCX 문서 열기와 편집
- 표·그림 작업, PDF 내보내기
- HWP/HWPX는 오픈소스 **rhwp** 소스 일부를 fork해 원본 재현 성능을 높였다고 합니다

### 📊 Spread

- 수식 계산, 정렬·필터, 차트

### 📽️ Present

- 슬라이드 쇼

### 📄 PDF
- 본문 텍스트 수정, 손글씨 서명
- 페이지 병합·추출·회전
- 양식 입력
- **한국어·영어 OCR**

사용법도 간단합니다. 파일을 화면에 **끌어다 놓으면** 형식에 맞는 편집기가 자동으로 열려요. 구형 **DOC·XLS·PPT** 파일도 브라우저 안에서 변환해 열 수 있지만, 변환 과정에서 일부 요소가 달라질 수 있다는 점은 알아두세요.

## 핵심 기술: WASM으로 브라우저에서 직접 처리

가장 눈여겨볼 부분은 아키텍처입니다. 많은 웹 문서 뷰어는 **서버에서 문서를 변환한 결과를 화면에 보여주는** 방식인데, SAMI Suite는 **브라우저가 문서를 직접 읽고 편집하고 저장**합니다.

브라우저에서 돌아가는 엔진은 다음과 같아요.

- **Go/WASM 문서 엔진** (Writer)
- **한글 문서 엔진**
- **PDFium 기반** PDF 처리
- PDF **글자 인식(OCR)** 도 브라우저 안에서 처리

저장하면 파일이 그대로 내 PC로 다운로드됩니다. 덕분에 **민감한 사내 문서나 개인 문서**를 다룰 때 외부 서버 유출 걱정을 줄일 수 있다는 게 큰 장점이에요.

---

## 앞으로의 계획: Embed SDK와 AI Agent

웹 편집기 외에도 이런 기능을 개발하고 있다고 합니다.

- **Embed SDK**: 다른 웹 서비스에 편집기를 넣을 수 있는 SDK
- **AI Agent**: 코드 작성 없이 내부 함수를 활용해 ChatGPT처럼 정밀하게 문서를 작성하는 기능. **Qwen3.8, Gemma4** 모델 기준으로 좋은 성능을 보였다고 해요.

**비즈니스 모델**도 깔끔합니다.
- 공개 웹 서비스는 **무료**
- 기업·기관 내부 설치나 SDK 도입은 **별도 계약**

## 알아두면 좋은 한계

개발자가 솔직하게 밝힌 현재 한계도 있습니다.

- 한컴오피스나 Microsoft Office의 **모든 기능과 서식을 똑같이 재현하지는 못합니다**
- 복잡한 표나 개체, 글꼴 구성에 따라 **원본과 다르게 보일 수 있습니다**
- 모든 처리를 브라우저에서 하다 보니, **큰 문서는 기기 성능의 영향을 받습니다**

개발팀은 특히 이런 피드백을 원한다고 하니, 써보시고 의견을 남겨보셔도 좋겠어요.

1. 실제 HWP·Office 문서에서 서식이 깨지거나 편집이 잘 안 되는 부분
2. 파일 열기부터 수정·저장까지 불편한 흐름
3. 결국 기존 프로그램을 다시 켜게 만드는 꼭 필요한 기능

## 설치형을 원한다면? Findex

웹 버전 말고 **설치형**으로 쓰고 싶다면, 앞서 공개된 로컬 문서 검색 도구 **Findex**에 SAMI Suite가 추가되었습니다. Findex를 설치하면 파일 확장자에 자동으로 연결해 쓸 수 있어요.

국내 환경에서 HWP는 늘 골칫거리였죠. 맥이나 리눅스 사용자, 혹은 프로그램 설치가 어려운 환경에서는 더 그렇고요. SAMI Suite는 **무료·무설치·무가입**에 **문서가 서버로 나가지 않는 구조**까지 갖춰, 가벼운 문서 작업용 도구로 충분히 써볼 만합니다. 아직 완벽한 재현은 어렵지만, 'HWP 한 줄 고치려고 한컴오피스 켜기'에 지치셨다면 한 번 써보시길 추천드려요!

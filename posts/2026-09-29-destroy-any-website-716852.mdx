## 한 줄 요약

주소창에 URL을 넣으면, 그 웹사이트가 **부술 수 있는 픽셀 아트 스테이지**로 바뀝니다. 스틱맨을 조종해 총을 쏘고 수류탄을 던지며 사이트를 무너뜨리는 게임, **Destroy Any Website**가 Show HN에 공개됐습니다.

## 어떤 게임인가요?

원리는 단순합니다. 플레이하고 싶은 웹사이트 주소를 입력하면, 해당 페이지의 레이아웃이 그대로 게임 레벨로 변환됩니다. 헤더, 버튼, 카드 같은 요소들이 발판과 구조물이 되고, 플레이어는 그 위를 뛰어다니며 하나씩 파괴하게 됩니다.

- 제작에는 타일맵 에디터인 **Sprite Fusion**이 사용되었습니다
- 혼자서 조용히 부숴도 되고, 친구들과 함께 난장판을 만들어도 됩니다
- 사이트를 다 부순 뒤에도 계속 때려 부수거나, 새로운 웹사이트를 골라 다시 시작할 수 있습니다

자신이 만든 서비스나 평소 즐겨 찾던 사이트를 넣어보는 순간이 이 게임의 진짜 재미 포인트입니다.

## 조작법 정리

키보드와 마우스만 있으면 됩니다. 전형적인 2D 액션 게임 조작 체계라 금방 익숙해집니다.

| 조작 | 동작 |
| --- | --- |
| `A` / `D` 또는 방향키 | 좌우 이동 |
| `Space` / `W` | 점프 (한 번 더 누르면 공중제비, 길게 누르면 **비행**) |
| `S` | 발판 아래로 내려가기 (길게 누르면 계속 통과) |
| 마우스 좌클릭 | 조준 후 사격 |
| 마우스 우클릭 | 수류탄 투척 |
| `1`~`7` 또는 마우스 휠 | 무기 전환 |

단순히 뛰고 쏘는 데서 끝나지 않고 **비행과 공중제비**까지 지원한다는 점이 인상적입니다. 화면에는 체력, 처치 수, 점수, 그리고 현재 파괴 진행 상황이 함께 표시돼 "얼마나 남았지?" 하는 긴장감을 만들어 줍니다.

일시정지 메뉴에서는 게임 재개, 현재 사이트 재시작, 새 웹사이트 선택, 방 나가기가 가능하고 배경과 사운드 설정도 조절할 수 있습니다.

## 친구들과 함께 부수기

멀티플레이어도 지원합니다.

1. 방을 만들고 **초대 링크를 복사**해 친구에게 전달합니다
2. 참가자들은 호스트가 웹사이트를 고르고 경기를 시작할 때까지 대기합니다
3. 경기 중에 메뉴를 열어도 게임은 계속 진행되니 주의하세요
4. 경기가 끝나면 바로 재대결이 가능하고, 다음 판 역시 호스트가 시작 버튼을 눌러야 합니다

호스트 중심으로 흐름이 통제되는 구조라, 여럿이 모였을 때 진행이 꼬이지 않는 점이 깔끔합니다.

## 내 사이트에 직접 심을 수도 있습니다

개인적으로 가장 흥미로운 기능은 **임베드**입니다. 제공되는 임베드 코드를 자신의 웹사이트에 붙여 넣으면, 방문자가 그 사이트에서 바로 "이 사이트 부수기"를 즐길 수 있습니다.

- 임베드 영역에서 **다크 테마 / 라이트 테마**를 선택할 수 있습니다
- 선택한 테마에 맞는 코드를 복사해 그대로 삽입하면 끝입니다

포트폴리오 사이트나 개인 블로그에 숨겨진 이스터에그로 넣어두면 방문자에게 꽤 강렬한 인상을 남길 수 있겠네요.

## 플레이 전 참고사항

한 가지 아쉬운 점은 **모바일을 지원하지 않는다**는 것입니다. 키보드와 마우스를 전제로 한 조작 체계이다 보니, 제작진도 노트북이나 데스크톱에서 플레이할 것을 안내하고 있습니다. 모바일에서 발견했다면 링크를 복사해 두었다가 나중에 PC에서 접속하는 편이 좋습니다.

## 마무리

실용성을 따지자면 0에 가까운 프로젝트입니다. 하지만 "웹사이트를 게임 레벨로 바꾼다"는 아이디어 하나만으로 충분히 기억에 남고, 웹 기술을 장난스럽게 비트는 Show HN다운 결과물이기도 합니다. 잠깐 쉬어 가는 시간에 자신의 사이트 주소를 한 번 넣어 보세요. 생각보다 훨씬 통쾌합니다.

## 들어가며

**숫자 2를 정확히 네 번 쓰고 수학 연산만으로 원하는 자연수를 만들어 보세요.** 단순해 보이는 이 퍼즐은 1920년대 수학자들 사이에서 유행한 놀이였던 것으로 보입니다. 처음에는 사칙연산만으로 시작하지만, 거듭제곱, 팩토리얼, 감마 함수, 복소수로 연산을 늘리다 보면 결국 **어떤 자연수든 만들 수 있는 일반해**에 이르게 됩니다. 이 일반해를 찾은 사람은 물리학자 **폴 디랙(Paul Dirac)**입니다.

## 핵심 요약

- 규칙: **숫자 2를 정확히 네 개** 사용하고, 다른 숫자 없이 수학 연산만으로 목표 자연수를 만듭니다.
- 사칙연산만으로도 **1부터 6까지** 만들 수 있습니다.
- 거듭제곱, 팩토리얼, 숫자 이어 붙이기(22, 222)를 허용하면 만들 수 있는 수가 크게 늘어납니다.
- 까다로운 7은 **감마 함수**를 쓰면 쉽게 풀립니다.
- 디랙의 일반해는 **제곱근 n번 중첩 + 밑이 2인 로그 두 번**으로 임의의 자연수 n을 만듭니다.

## 1단계: 사칙연산만으로

가장 기본적인 규칙에서도 꽤 많은 수를 만들 수 있습니다.

```text
1 = (2 + 2) / (2 + 2)
2 = 2/2 + 2/2
3 = 2 × 2 − 2/2
4 = 2 + 2 + 2 − 2
5 = 2 × 2 + 2/2
6 = 2 × 2 × 2 − 2
```

하지만 7부터는 사칙연산만으로 만들기가 쉽지 않습니다.

## 2단계: 거듭제곱과 팩토리얼 허용

거듭제곱과 팩토리얼을 쓰면 만들 수 있는 수의 범위가 크게 늘어납니다.

```text
18    = 2^(2^2) + 2
28    = (2 + 2)! + 2 + 2
256   = (2 + 2)^(2 + 2)
65536 = 2^(2^(2^2))
```

## 3단계: 숫자 이어 붙이기

`22`를 2 두 개를 쓴 것으로 인정하면 또 다른 조합이 가능해집니다.

```text
26  = 22 + 2 + 2
11  = 22 / √(2 + 2)
444 = 222 × 2
```

## 4단계: 감마 함수와 복소수

까다로운 **7**은 감마 함수를 쓰면 간단히 만들 수 있습니다. 감마 함수는 팩토리얼을 일반화한 함수로, `Γ(n) = (n−1)!`이므로 `Γ(2) = 1`입니다.

```text
7 = Γ(2) + 2 + 2 + 2
```

관련 토론에는 적분, 순환소수, 조합 연산을 활용한 풀이도 있습니다. 복소수를 쓰는 예도 있습니다.

```text
12 = |2 + 2√(−2)|²
```

`√(−2) = √2·i`이므로 절댓값의 제곱은 `2² + (2√2)² = 4 + 8 = 12`가 됩니다.

## 디랙의 일반해: 제곱근과 로그의 조합

하나하나 따로 풀던 퍼즐을 **한 번에 끝내는 방법**이 있습니다. 핵심은 **제곱근을 반복하면 반복 횟수가 지수에 나타난다**는 점입니다.

```text
√2       = 2^(2^−1)
√√2      = 2^(2^−2)
√√√2     = 2^(2^−3)
...
제곱근 n번 = 2^(2^−n)
```

여기에 **밑이 2인 로그**를 차례로 적용합니다.

1. 로그를 한 번 취하면 `2^−n`이 됩니다.
2. 한 번 더 취하면 `−n`이 됩니다.
3. 부호를 바꾸면 목표 수 **n**이 나옵니다.

```text
n = −log₂( log₂( √√…√2 ) )   ← 제곱근 n번
```

### 2를 정확히 네 개 맞추기

위 식에 쓰인 2는 **세 개**입니다(로그의 밑 두 개, 가장 안쪽의 2 하나). 바깥 로그의 밑을 `√(2+2)`로 바꾸면 값은 그대로 2이고, 2는 정확히 **네 개**가 됩니다.

```text
n = −log_√(2+2)( log₂( √√…√2 ) )   ← 제곱근 n번
```

여기서 **n은 식에 들어가는 숫자가 아니라 제곱근을 몇 번 겹쳤는지를 나타내는 표기**입니다. 예를 들어 7을 만들려면 제곱근을 일곱 번 겹쳐 쓰면 됩니다.

```text
7 = −log_√(2+2)( log₂( √√√√√√√2 ) )
```

## 편법일까, 정답일까?

편법처럼 보일 수도 있지만, 이 풀이는 **2 네 개와 제곱근, 로그 같은 기본 연산만** 사용하므로 퍼즐 규칙을 지킵니다. 이제 어떤 자연수든 표현할 수 있고, 남은 어려움은 **중첩된 제곱근을 빠짐없이 그리는 일**뿐입니다.

## 마치며

이 퍼즐은 **허용하는 연산에 따라 문제의 난이도가 크게 달라진다**는 점을 보여 줍니다. 사칙연산에서는 6에서 막히지만, 연산을 조금씩 늘리면 7을 넘어 65536까지 만들 수 있고, 결국 모든 자연수를 만드는 일반해에 이릅니다. 개별 사례를 하나씩 풀지 않고 **문제의 구조를 이용해 한 번에 해결하는** 접근은 프로그래밍에서 알고리즘을 설계할 때와도 닮았습니다. 직접 2 네 개로 7, 9, 10을 만들어 보세요!
